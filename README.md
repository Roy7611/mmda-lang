# mmda-lang
元数据模型驱动架构（MMDA）语言

用图形化设计工具设计架构与领域模型，**元数据作为唯一真源**，生成 Java / C# / TS 三端代码；内核计划为 **Rust 单实现**，对外只出 C ABI（cdylib）与 WASM 两个面（尚未开工）。

本仓是**语言规范真源**（docs-only），不是实现仓。
