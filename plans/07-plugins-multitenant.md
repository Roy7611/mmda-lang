# 07 多租户插件（租户独有的插件：开发 / 配置 / 加载 / 卸载）

> **问题（作者 2026-09-26）**：「你有没有考虑多租户下，**租户独有的插件**如何开发、配置、加载/卸载？」
> 现有口径：[`../doc/runtime.md`](../doc/runtime.md) **§7 业务功能模块插件**（§7.1 插件 = `module`、§7.2 包形态与清单、§7.3 数据模型硬约束、§7.4 装载与运行语义、§7.5 二开链路）、[`../doc/ide/plugins.md`](../doc/ide/plugins.md) §11 权限与硬边界 / **§12 加载形态（✔ 已裁 = WASM 组件）**、[`../PLAN.md`](../PLAN.md) §6.3-17 / §6.3-38 / **§6.3-40**。
> **实测缺口**：现有 §7 全篇**没有租户维度**（装载、清单、隔离都在讲"装/不装"，没讲"**给哪个租户装**"）—— 本文补这一层。

## 1. 先摆事实：多租户在 MMDA 里已经有地基

| 事实 | 出处 |
| --- | --- |
| 多租户 = **共享表 + 租户键**（`BIGID` 高 28 位 tenantId、低 36 位 realId） | [`../doc/lang/datatypes.md`](../doc/lang/datatypes.md) §3、[`../doc/lang/records.md`](../doc/lang/records.md) §2.3 |
| 插件 = **`module`**（语言层零新增、插件不侵入语法） | [`../doc/runtime.md`](../doc/runtime.md) §7.1、[`../PLAN.md`](../PLAN.md) §6.3-10 |
| 插件数据模型硬约束：只在自己 module 内新建、**不许改他人表结构**、不许直读对方库表、装载期**冲突即拒载** | [`../doc/runtime.md`](../doc/runtime.md) §7.3 |
| 加载形态：**WASM 组件**（wasmtime + component model；文件/网络/进程必须经宿主函数按能力白名单暴露） | [`../PLAN.md`](../PLAN.md) §6.3-40、[`../doc/ide/plugins.md`](../doc/ide/plugins.md) §12 |
| 隔离级别：受信插件**首版进程内 + 命名空间与冲突检测**；**进程级隔离留给不可信第三方** | [`../doc/runtime.md`](../doc/runtime.md) §7.4（§9-8） |

**推论（本文的出发点）**：**"租户独有的插件" ≠ "租户独有的表"** —— 表天然是共享 + 租户键，所以真正要新建的是**装配与可见性的租户维度**，不是数据的租户维度。

## 2. 方案：给插件加一层「租户维度」

### 2.1 清单新增字段（`mmda-plugin.json`）

| 字段 | 含义 | 缺省 |
| --- | --- | --- |
| `scope` | `global`（全租户）/ `tenant`（指定租户） | `tenant`（**保守缺省：不写就是只给声明的租户**） |
| `tenants` | 租户白名单（`scope: tenant` 时必填；可含 `*` 表示"允许按租户逐步放量"） | 无 |
| `segments` | 本插件新增实体**要占的段**（`[minId, maxId]`，可多条） | 无（不许共用默认段，见 D24） |
| `modules` | 已有字段（一插件可多 module） | — |
| `kernel` / `capabilities` / `signature` | 已有字段（兼容范围 / 最小权限 / 签名） | — |

**装载期校验（冲突即拒载，沿用 §7.3 语义）**：① 段与平台既有段、**与已装插件的段**两两不重叠；② `module` id / 表名 / 端点 / 权限码 / 事件名不撞车；③ `kernel` 兼容范围匹配；④ 签名校验通过。任一条不满足 → **拒载 + 审计**（不静默覆盖）。

### 2.2 数据模型（租户插件建表）

- **默认：表租户共享**（靠租户键隔离，零额外成本）；插件建表由 `mmda gen` 产出 DDL 随包走（**DDL 进生成清单 + 指纹**，见 [`06-codegen.md`](06-codegen.md)）。
- **要结构差异**（某租户多两列）→ 走**扩展表 `xxx_ext`**（承 [`../PLAN.md`](../PLAN.md) §6.3-30 ⑩ 「不许给他人表加字段」的精神），**不许**按租户建独立表。
- **插件里的实体必须领段**（`@Partitioned`）→ 段进清单、装载期校验（D24）。这条把"插件新增实体"纳入既有的**段硬门禁**，是本文最实的机制。
- 平台级公共数据（`NO_TENANT_ID = 0`）**要显式声明**，否则默认租户内。

### 2.3 隔离分档（**不是二选一，是同一份清单的两档**）

| | 受信插件（交付团队 / 伙伴） | 不可信插件（租户自助上传） |
| --- | --- | --- |
| 代码形态 | 进程内：Java `jar` / C# `dll` | **WASM 组件**（wasmtime + component model） |
| 隔离 | 命名空间/包前缀 + 子加载器（§9-8 已裁） | **沙箱 + 能力白名单**（宿主函数只暴露清单里声明的 capability） |
| 段与表 | 同上（清单声明 + 装载期校验） | 同上 |
| 前提 | **签名三级**（官方 / 发布者 / 企业私有）；签名不符 → 拒载 | 同上 + 能力白名单强制 |

> 同一份插件源码可以**先按受信档跑通、再上 WASM 档**（与 §6.3-40 的"A 降备选口子"一致）。

### 2.4 加载 / 停用 / 卸载（分档，别许愿）

| 动作 | 受信插件（进程内） | 不可信插件（WASM） |
| --- | --- | --- |
| **热装载** | ✅ module 粒度（§7.4 已裁） | ✅ 实例化即可 |
| **停用** | ✅ 注册表摘除 + 路由下线 + **数据保留** | ✅ 同 |
| **真卸载** | ⚠️ **首版不做**：Java `URLClassLoader` 卸载不可靠（引用泄露）、C# `AssemblyLoadContext` 可卸载但需保证无引用 —— 首版只承诺"停用" | ✅ **真卸载**（drop instance + 清宿主函数注册） |
| **按租户灰度** | ✅ `tenants` 白名单逐步放量 | ✅ 同 |
| **升级** | ✅ 换包重装；**手写物不被覆盖**（生成清单 + 指纹保证） | ✅ 同 |
| **回滚** | ✅ 停用 + 回退旧版本包（数据不删） | ✅ 同 |
| **数据清除** | ❌ 不随停用发生；`mmda plugin purge --tenant X --plugin Y` **显式不可逆** + 审计 | ✅ 同 |

**命令面（建议）**：`mmda plugin list|install|enable|disable|upgrade|purge --tenant <id>`；**租户维度的开关进运维面**（[`../doc/operations.md`](../doc/operations.md) 的配置管理与审计）。

### 2.5 配置

- **租户级配置进 `RuntimeProfile`**（承既有口径"配置管理 = 元数据即配置、环境差异只进 Profile"）：`profile.tenants.<tenantId>.plugins.<pluginId>.{enabled, config}`；
- **配置漂移检测**照旧：生效版本 ≠ git 提交哈希 → 告警；
- 插件自带默认配置随包走（进生成清单），租户覆盖只写差异项。

### 2.6 UI 与权限

- **UI**：租户专属面板/菜单/路由由 `MetaUi` 产物按**提供方插件**过滤 —— 需要在 `MetaUi` 里标**插件归属**（现状缺这个字段，属待办）；前端按该租户的插件集渲染。
- **权限**：**租户管理员只能管自己租户**的插件开关；**跨租户安装/卸载/升级 = 平台权限**（`system` 身份 + 审计，承 [`../doc/runtime.md`](../doc/runtime.md) §4.6 的 runAs 口径）；装/卸动作一律进审计。

### 2.7 可测（验收条款，按 [`04-verification.md`](04-verification.md) 的规范化成用例）

| 用例 | 期望 |
| --- | --- |
| 租户 A 装了插件 P、租户 B 没装 | A：module/端点/表可用；B：调用该端点 **404/未装载**（**不是 500**）；B 的元数据里**看不到** P 的对象 |
| 数据隔离 | A 的数据 B 看不到（租户键过滤），即使同一张表 |
| 段冲突 | 插件声明的段与既有重叠 → **拒载** + 明确报错（含冲突段与来源） |
| 停用 | 端点下线、**数据仍在**；重新启用后数据可用 |
| 真卸载（WASM 档） | 实例销毁、宿主函数注册清空、无泄漏 |
| 配置漂移 | 生效版本 ≠ 提交哈希 → 告警 |

## 3. 与既有裁定的关系（不新造概念）

- **插件 = module**（§7.1）不动；本文只加"这个 module 给哪个租户"的**一层过滤**。
- **隔离级别**（§9-8 首版进程内）不动；本文把"不可信第三方"的口子（WASM，§6.3-40）**接到租户自助场景**上。
- **段硬门禁**（同组不重叠）不动；本文**把插件新增实体纳入它**。
- **生成清单 + 指纹**（[`06-codegen.md`](06-codegen.md)）不动；本文要求**插件包内也带清单**（升级不覆盖手写物靠它）。
- **配置即元数据**（`operations.md` §9 配置管理）不动；本文只加租户段。
