## 一句话方案

**Rust 手写词法器 + 手写递归下降 → 无损 CST（逐字节可还原） + 强类型 AST → 静态校验 → 三端生成 → LSP**；
**不用 ANTLR / 语法生成器**（第一次的教训：672 行 `.g4` 全废；第二次：3 个 `.g4` + 12 个生成类 59,020 行正在删）；
**不靠"读代码"取信**，靠三条自动判据：**规范用例集全绿（正例 + 反例）** + **parse→print 逐字节无损** + **每条硬门禁一条能定位到行列的反例**。

**语料的定位（✔ 2026-09-26 作者纠正）**：那 372 个文件是**历史逆向工程产物，语法仍在调整** —— 所以它**只是**（a）解析器的**冒烟输入**（不崩、诊断可定位）、（b）**语法漂移报告**的素材、（c）性能负载；**绝不作验收基准**（不设"372 文件 0 error"这类门禁）。**验收基准 = `doc/` 规范 + `errata` 已裁项，逐条落成用例**（见 [`04-verification.md`](04-verification.md) §1）。
